# 🚀 설치 가이드 (React Native + Expo)
## 📦 필수 환경

### Node.js: 22.19.0

### npm: 11.6.0

## 🔧 Node.js 설치 방법
공식 Node.js 다운로드 페이지
에서
LTS가 아닌, 정확히 22.19.0 버전을 선택해 설치하세요.

설치 확인:

```bash
node -v
v22.19.0
```

## 🔧 npm 설치 / 업그레이드 방법

npm은 Node.js 설치 시 함께 제공되지만, 버전을 맞춰야 합니다.

현재 프로젝트는 npm 11.6.0 필요합니다.

### npm 버전 확인
```bash
npm -v
# 11.6.0
```

### 업그레이드
```bash
npm install -g npm@11.6.0
```


## 의존성 설치
프로젝트 루트에서 실행하시면 됩니다.
```bash
npm install
```

### 실행
```bash
npx expo start
```
